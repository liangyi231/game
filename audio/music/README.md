# 背景音乐目录

游戏启动时 autoload `Music`（`scripts/audio/music.gd`）会自动循环播放本目录的音乐。

## 命名约定

| 文件名 | 说明 |
|---|---|
| `bgm.ogg`（优先） | 主背景音乐，放进来就自动循环 |
| `una_mas_funk_2.ogg` | 备用名，没有 `bgm.*` 时读取 |
| 支持扩展名 | `.ogg` 优先，其次 `.wav` / `.mp3` |

- 循环由代码显式开启（OGG 设 `loop=true`，WAV 设 `LOOP_FORWARD`），并留了 `finished → 重播` 兜底
- 音量默认 -12 dB；游戏内按 **M** 静音/恢复
- 缺文件时静默，不影响战斗

## 当前文件

`bgm.wav` 是 `tools/make_bgm.py` 生成的**原创占位**：132 BPM、8 小节（约 14.55 秒）无缝循环。
编曲层次：四踩底鼓 + 切分底鼓、2/4 拍手、16 分 hi-hat、锯齿贝斯带侧链压缩感、反拍和弦 stab、
后半段 16 分琶音、末小节军鼓滚奏 + 上升噪声。它不是任何现有歌曲。
