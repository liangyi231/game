# 音效目录（存档约定）

把音效文件放在本目录，文件名对上就会自动播放；缺文件时静默跳过，不影响战斗。

支持格式：`.ogg`（推荐）> `.wav` > `.mp3`。
播放器：autoload `Sfx`（`scripts/audio/sfx.gd`），8 路复用、默认 -6 dB。

## 当前接线

| 文件名 | 来源 | 触发时机 |
|---|---|---|
| `seek.wav` | 桌面视频「Seek Seek（与我何干）」 | **大肥鱼行动音效**：玩家出任意牌 |
| `laugh.wav` | 桌面视频（奶龙捧腹大笑那段） | **奶龙行动音效**：奶龙出手 / 格挡 |
| `seekseek.wav` | 旧视频抽轨（待作者替换） | **受击音效**：任何角色实际掉血（格挡吸收不响） |
| `deepdepp.wav` | 旧视频「Deep Deep（放开我）」 | 备选，未接线；想换成 deep 就把玩家行动改播它 |

音轨由 `ffmpeg` 抽取，做了首尾静音裁剪与响度归一（-16 LUFS / TP -1.5）。

## 想换/加音效

直接替换同名文件，或在 `scripts/battle/battle_screen.gd` 里改 `_sfx("名字")`，再把同名文件丢进来即可。
