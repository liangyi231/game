# 音效目录（存档约定）

把音效文件放在本目录，文件名对上就会自动播放；缺文件时静默跳过，不影响战斗。

支持格式：`.ogg`（推荐）> `.wav` > `.mp3`。
播放器：autoload `Sfx`（`scripts/audio/sfx.gd`），8 路复用、默认 -6 dB。

## 当前约定

| 文件名 | 触发时机 |
|---|---|
| `deepdepp.wav` | **行动音效**：玩家出任意牌、奶龙出手 |
| `seekseek.wav` | **受击音效**：任何角色实际掉血（格挡吸收不响） |

> 音频素材由作者本人提供/替换，直接覆盖同名文件即可，无需改代码。
> 当前文件是从视频抽轨的临时版本。

## 可加但暂未接的

| 文件名 | 触发时机 |
|---|---|
| `victory.ogg` / `defeat.ogg` | 战斗结算（当前无文件→静默） |
| `click.ogg` | 点击（未接入） |

## 想换/加音效

直接替换同名文件，或在 `scripts/battle/battle_screen.gd` 里加 `_sfx("名字")`，再把同名文件丢进来即可。
