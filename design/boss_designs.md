# 《大肥鱼传说》Boss 设计提案 v0.1

> 定位：2D 弹幕肉鸽，局内结构参考《崩坏：星穹铁道》模拟宇宙（节点地图 → 战斗 / 事件 / 祝福 → 精英 / Boss）。
> 本文档把「网络热梗 Boss」改造成**完全原创**的角色：保留梗的识别特征（圆胖脸、呆眼、反差凶、气味梗、大饼脸偶像），丢掉原形象与原名，规避著作权与商标风险。
> 占位立绘已由 `tools/gen_boss_placeholders.py` 生成到 `art/placeholders/`，可直接进 Godot 当临时美术。

---

## 0. 世界观框架：「互联网物种图鉴」

把每一层的 Boss 设定成一种**网络现象的拟人化物种**，玩家在图鉴里解锁它们。这样做的三个好处：

1. 梗感来自「物种设定」而不是「抄形象」，越做越有原创性；
2. 节点地图里 Boss 节点可以做成「图鉴编号 XXX」的收集感；
3. 后续加 Boss 只需要加「一种网络现象」，不依赖某个具体 IP 的热度周期。

统一美术语汇（所有 Boss 共用，保证风格统一）：

| 项目 | 规范 |
| --- | --- |
| 画布 | 512×512，透明背景，游戏内缩放到 240–320px 显示 |
| 描边 | 4–6px 深棕黑 `#2B221C`，圆头连接 |
| 上色 | 平涂 2 色（主色 + 亮部），禁止渐变和写实高光 |
| 五官 | 极简：豆眼 / 呆眼 / 星星高光 + 腮红 |
| 反差 | 外形必须可爱，弹幕必须凶狠——这是整个游戏的爽点来源 |

## Boss 01 · 奶膘兽（Milk Paunch）

![奶膘兽](art/placeholders/boss_1_milkbeast.png)

| 项 | 内容 |
| --- | --- |
| 图鉴编号 | 001 |
| 梗来源 | 「圆胖呆萌 + 反差暴戾」这一类胖娃娃型网络形象 |
| 识别特征 | 奶油黄圆饼身、两只圆耳朵、呆滞小眼、w 形嘴、粉色腮红、小短手与圆尾巴 |
| 自称台词 | 「咕噜……你也想吃一口吗？」 |
| 暴走台词 | 「都给你吃，吃死你。」 |
| 性格 | 慢、黏、迟钝，被激怒后完全失控 |
| 配色 | 身体 `#FAE3AC`、亮部 `#FFF6DB`、腮红 `#F48F8F`、描边 `#2B221C` |

### 弹幕主题：糖浆 / 奶泡 / 糖晶

| 阶段 | 血量节点 | 招式 | 弹幕设计 | 预告 |
| --- | --- | --- | --- | --- |
| P1 糖浆 | 100% → 70% | 糖浆雨 | 慢速大弹从上方落下，弹速约 90px/s，落点带小范围减速黏地 | 身体前后摇晃 |
| P2 膨胀 | 70% → 35% | 奶泡扩散 | 身体放大 1.4 倍；大弹（慢、大）命中后分裂成 6 颗小弹 | 身体先缩再猛胀，屏幕轻微震动 |
| P3 暴走 | 35% → 0% | 糖晶暴食 | 环形 12 发 + 顺时针螺旋，节奏逐轮加快；眼睛变红 | 全身闪白 + 眼睛由黑转红 |

### 素材料清单

- 立绘 1 张（本图）
- 表情差分 3 张：呆 / 胀大 / 暴走（眼睛红 + 裂纹）
- 部件拆分（可选）：左右手、尾巴，用于挤压拉伸动画
- 粒子：糖浆滴落（`GPUParticles2D`）、糖晶碎片

## 弹幕 Pattern ↔ Godot Resource 映射

所有招式都做成 `BulletPattern.tres`，Boss 脚本只负责「按时间表切换 Pattern 列表」，加招式不改代码。

```gdscript
# scripts/bullet/bullet_pattern.gd
class_name BulletPattern
extends Resource

@export_enum("ring", "spiral", "fan", "aimed", "orbit", "heart") var shape: String = "ring"
@export var bullet_count: int = 12
@export var speed: float = 120.0
@export var interval: float = 0.4        # 每轮间隔
@export var rounds: int = 1              # 连发轮数
@export var spread_deg: float = 360.0    # 扇形张角
@export var spin_speed: float = 0.0      # 螺旋/光柱角速度
@export var color: Color = Color("#FF4FA3")
@export var bullet_radius: float = 6.0
@export var speed_curve: Curve           # 弹速随时间变化（减速/加速）
```

Boss 阶段数据：

```gdscript
# 每层 Boss 的阶段配置
var phases := [
    {"hp_ratio": 1.00, "patterns": [p1_a, p1_b], "duration": 20.0},
    {"hp_ratio": 0.70, "patterns": [p2_a],        "duration": 25.0},
    {"hp_ratio": 0.35, "patterns": [p3_a, p3_b],  "duration": 30.0},
]
```

## 命名与合规提醒

1. **名字也别撞**：「奶龙」「臭企鹅」「菲比」既是角色名也是注册商标/知名标识，直接沿用可能构成商标侵权或不正当竞争。本文档给的都是自造词。
2. **AI 精修时别投喂原图**：把梗图当参考图丢进图生图，生成结果可能构成「实质性相似」，反而坐实侵权。只用文字描述 + 自己的占位图当垫图。
3. **留档**：每个 Boss 的设计草图、生成记录、修改历史都存进 `design/`，万一被质疑原创性，这是最有力的证据链。
4. 上线前统一过一遍版权清单，写进 `CREDITS.md`。
