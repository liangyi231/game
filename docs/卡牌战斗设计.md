# 《大肥鱼传说》卡牌战斗设计 v0.1

> 方向变更（2026-11-01）：由原「2D 弹幕肉鸽」改为**类似《杀戮尖塔》的卡牌构筑对战**。
> 现有 Boss 立绘（奶膘兽 / 发酵企鹅 / 大饼脸偶像）直接复用为卡牌战敌人，原弹幕设计暂存 `design/boss_designs.md`。

## 一、已实现（可玩竖切片）

- 场景：`scenes/battle.tscn`（启动场景），逻辑在 `scripts/battle/`，数值在 `scripts/cards/card_db.gd`
- 主角：**鲸娘**（蓝发鲸尾少女，`art/characters/whale_girl.png`），战斗界面左侧立绘，与右侧敌人对称；参考图是 `art/characters/main_char_ref.jpg`，由 `tools/make_char_cutout.py` 抠掉白底生成透明 PNG
- 玩家：生命 70，每回合能量 3，手牌上限 5
- 循环：玩家回合 → 出牌 → 结束回合 → 敌人按**意图预告**行动 → 格挡清零 → 能量回满 → 补牌到 5 张
- 牌堆：抽牌堆 / 手牌 / 弃牌堆三段循环，弃牌堆空了会洗回抽牌堆
- 胜负：敌人生命归 0 胜利；玩家生命归 0 败北；可「重新开始」
- 布局：**绝对定位**。背景按 cover×1.12 放大，草坪线固定在屏幕 72% 高度；鲸娘/奶龙缩到 200×230，脚底对齐草坪线站在草地上；敌人抬手过渡 0.1s（放大 1.06、前移 8px，脚底锚点）
- 头顶信息：名字 / 生命 / 格挡 / 状态显示在角色头顶，敌人额外显示意图；底部能量改名为「大米饭」
- 手牌：扇形排布（±12° 摆角、间距≤116px、边缘卡下沉）。**入牌动画**错峰从下方上浮 + 淡入；**悬停**按「手牌区里离光标最近的牌」判定（不依赖 enter/exit，避免卡片抬起后离开光标下方触发抖动），抬起 58px、放大 1.16，但**保留扇形角度不拉直**，同时邻牌让位并淡入金色描边；效果浮窗 `z_index=1000` 按文字高度自适应
- 卡面质感：`art/ui/card_round.gdshader` 做圆角遮罩，卡后加柔和投影（StyleBoxFlat shadow），文字衬底也改成圆角，整体更"光滑"
- 出牌方式：**拖拽出牌**——按住卡牌跟手拖动（放大到 1.1、旋转回正），松开时若牌心在草坪线以上就打出（从松开位置起飞焚烧），否则用 BACK 缓动弹回手牌；**不拖动直接点一下**也能直接打出
- 旋转修复：悬停/离开的 tween 互相打断时会把旋转卡在 0，现在恢复手牌时会同时把 rotation 与 scale 归位，扇形不会"变直"
- 出牌动画：过冲起飞（0.34s，TRANS_BACK 带轻微回弹）→ 空中回正收势（0.12s）→ 中央**白闪**（0.14s）→ 焚烧（0.45s，变橙红、放大到 1.95、上飘淡出）→ 才结算效果；手牌同时平滑收拢，整段约 1.05s
- 美术：卡面 `art/ui/card_face.jpg`（深蓝金纹龙鱼），战斗背景 `art/bg/night_sky.jpg`（像素夜景，叠 34% 深色遮罩保证文字可读）
- 敌人节奏：抬手蓄力 0.45s → 出手结算 → 停留 0.85s → 收尾 0.2s，**动作播完才开玩家新回合**，期间手牌与「结束回合」锁定（实测整段约 1513ms）
- 受击特效：角色整体变红（`modulate=(2.4,0.35,0.35)`）0.24s 缓动恢复，同时头顶飘 `-N` 伤害数字（0.8s 上浮淡出，`fx_layer` z=900），并播 `hurt` 音效
- 音效：autoload `Sfx`（`scripts/audio/sfx.gd`，8 路复用）。**玩家出牌 → `seekseek`（Seek Seek）**、**奶龙出手 → `laugh`（大笑）**、受击 → `hurt`（**原创合成撞击音**，不含人声）。Deep Deep 相关音频与 `.godot` 缓存残留均已清除，见 `audio/sfx/README.md`
- 背景音乐：autoload `Music`（`scripts/audio/music.gd`）循环播放 `audio/music/bgm.*`；当前是用 `tools/make_bgm.py` 生成的原创 funk 占位（108 BPM、8.89s 循环），`M` 键静音。正式曲目取得授权后覆盖 `bgm.ogg` 即可，见 `audio/music/README.md`
- 全屏：启动即全屏（`display/window/size/mode=3`），`F11` 切全屏/窗口，`Esc` 退出全屏；拉伸用 `canvas_items + expand`，宽高比不拉伸，多出来的空间给战场而不是把画面拉扁
- 中文字体：运行时用 `SystemFont`（微软雅黑），不依赖项目内字体文件

### 状态系统

| 状态 | 效果 | 递减时机 |
|---|---|---|
| 易伤 vulnerable | 受到伤害 ×1.5 | 拥有者回合结束时 -1 |
| 虚弱 weak | 造成伤害 ×0.75 | 拥有者回合结束时 -1 |
| 中毒 poison | 自己回合开始掉 N 点血，**无视格挡** | 每次结算后 -1 |

- 伤害修正顺序：先算攻击方虚弱，再算受击方易伤，向下取整
- 中毒每回合掉血，UI 也会触发受击音效

## 二、数值约定

- 伤害先扣格挡、溢出才扣生命
- 玩家格挡在**新回合开始时清零**；敌人格挡在自己行动前清零
- 出牌即时结算，无动画（v0.2 再加卡牌位移/受击震屏）
- 敌人意图**提前一回合明示**，这是杀戮尖塔式决策的核心信息

art/enemies/nailong_idle.png    奶龙站立帧（透明，1439×1857）
art/enemies/nailong_action.png  奶龙抬手帧（透明，与站立同画布）

art/bg/night_sky.jpg            战斗背景（图二，像素夜景）

新增一张牌 = 在 `card_db.gd` 的 `CARDS` 里加一条 + 加进初始牌组；不需要改 UI。

## 四、下一步（按优先级）

1. **卡牌池扩充**：状态（易伤/虚弱/中毒）、多段攻击、费用变化、消耗（Exhaust）、能力牌（Power，本场持续生效）
2. **手感**：出牌动画、抽牌动画、受击震屏；音效接入点已就位（等素材：见 `audio/sfx/README.md`）
3. **地图与奖励**：节点地图（参考模拟宇宙/尖塔），战斗后三选一卡牌、金币、事件
4. **遗物系统**：局内被动，构筑差异化
5. **更多敌人**：发酵企鹅（减速/毒）、大饼脸偶像（多段/召唤），各自意图模式
6. **存档**：局内进度 + 图鉴解锁

## 五、风险与注意

- 卡牌游戏的重心在**数值与卡池**，不在画面；先保证 20~30 张牌的平衡与手感，再堆美术
- 与另一条线的弹幕原型（`design/character_rig.md`、`scenes/player_rig.tscn`）互不冲突：两者共用角色与 Boss 素材，可后续选一条主线
