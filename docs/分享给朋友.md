# 把 demo 分享给朋友（电脑 / 手机）

> 朋友不用装 Godot、不用懂技术：电脑双击 exe，手机点开网页即可。

## 已经打好的包（都在 `dist/` 里）

| 文件 | 大小 | 用途 |
| --- | --- | --- |
| `大肥鱼传说-电脑版.zip` | ~48 MB | **电脑首选**：解压得到单个 `大肥鱼传说.exe`，双击即玩 |
| `大肥鱼传说-网页版.zip` | ~21 MB | **手机用**：上传到 itch.io / Netlify 变网址，或本地起服务 |
| `大肥鱼传说-电脑版便携版.zip` | ~100 MB | 备用：万一 exe 被杀毒误杀，解压双击 `开始游戏.bat`（内置运行器，需要约 13MB 资源缓存，已在包内） |
| `dist/web/` | — | 网页版解压后的目录，给本地服务用 |

导出模板已装到 `%APPDATA%\Godot\export_templates\4.7.2.stable`，以后重新打包直接用下面的命令。

## 一、电脑（Windows）

1. 把 `dist/大肥鱼传说-电脑版.zip` 通过微信 / QQ / 网盘发给朋友（48MB，微信可直接发）。
2. 朋友解压后双击 `大肥鱼传说.exe`。
3. 如果 SmartScreen 提示"未知发布者"：点「更多信息」→「仍要运行」。

操作：拖拽卡牌到草坪线以上松手出牌（也可单击）；底部「结束回合」；「设置」调音量；F11 全屏、M 静音。

## 二、手机 —— 网页版

手机不能跑 exe，用 Web 导出。`dist/大肥鱼传说-网页版.zip` 解压后是 `index.html` 等文件。

### 本机怎么打开网页版（最快）

- 双击 `tools/打开网页版.bat`：会自动起服务并打开浏览器 `http://127.0.0.1:8080/index.html`。
- 或者手动：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/serve_web.ps1`。

> 注意：**不能直接双击 `dist/web/index.html`**，浏览器用 `file://` 加载会拦 wasm / pck，页面会黑屏或报错。

### 方案 A：同一 Wi-Fi 直接玩（最快，不用注册）

在项目目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/serve_web.ps1
```

它会打印两个地址：

- 电脑：`http://localhost:8000`
- 手机：`http://<电脑局域网IP>:8000`

手机连同一个 Wi-Fi，浏览器打开第二个地址，**横屏**玩。
（第一次运行 Windows 防火墙会询问，允许"专用网络"即可；不行就临时关闭防火墙。）

### 方案 B：变成公网网址（朋友不在身边也能玩）

| 平台 | 做法 | 说明 |
| --- | --- | --- |
| **Netlify Drop** | 打开 <https://app.netlify.com/drop>，把 `dist/web` 文件夹拖进去 | 最快，几秒出网址，可先不注册试用 |
| **itch.io** | New Project → Kind 选 **HTML** → 上传 `dist/大肥鱼传说-网页版.zip` → 勾选 "This file will be played in the browser" | 适合长期分享，可设密码/公开 |
| **GitHub Pages** | 把 `dist/web` 内容推到仓库，Settings → Pages 选分支 | 需要能 push 到 GitHub |

> 网页版必须通过 http(s) 访问，**不能双击 index.html 用 `file://` 打开**（浏览器会拦 wasm）。

## 三、给会 Godot 的朋友（可选）

把项目压缩（排除 `.godot/`、`.git/`、`dist/`）发过去，对方用 Godot 4.7.2 导入 `project.godot` 按 F5。

## 手机 / 网页的已知限制

- **没有鼠标悬停**：卡牌说明、状态图标说明依赖 hover，触屏上要按住拖动才可能触发，后续可以加"点一下显示"。
- 建议**横屏**；竖屏会留黑边。
- 浏览器限制自动播放，点「开始游戏」之后才会出声。
- iPhone 建议 iOS 15+ / 最新 Safari；安卓用 Chrome、Edge 都行。
- 首次加载要下载 38MB wasm + 12MB pck，Wi-Fi 下几秒到十几秒。

## 重新打包（自己改完代码后）

```powershell
$godot = 'D:\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe'

# 电脑版（单文件，内嵌 pck）
& $godot --headless --path . --export-release "Windows Desktop" "dist\windows\大肥鱼传说.exe"
Compress-Archive -Path 'dist\windows\大肥鱼传说.exe' -DestinationPath 'dist\大肥鱼传说-电脑版.zip' -Force

# 网页版
& $godot --headless --path . --export-release "Web" "dist\web\index.html"
Compress-Archive -Path 'dist\web\*' -DestinationPath 'dist\大肥鱼传说-网页版.zip' -Force
```

导出预设见 `export_presets.cfg`（`dist/`、`export_presets.cfg` 都不入库）。
