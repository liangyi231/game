# 大肥鱼传说 · 资源库清单（AI 可直接取用）

> 来源：用户 2026-11-01 提供的开源 Godot 资源合辑。
> 用途：让 AI 优先复用成熟资源 / 现成系统，减少从零造轮子。
> 约束：**用户没有翻墙**。本机实测（见文末）GitHub 可直连，PyPI 官方源不通（走清华镜像），
> GitHub Release 下载 CDN 不稳（`objects.githubusercontent.com` 常被重置，改用 `git clone` 取源码）。

## 四、本机网络实测（2026-11-01）

| 站点 | 结果 |
|---|---|
| github.com / raw.githubusercontent.com / api.github.com | ✅ 直连可用 |
| codeload.github.com（`git clone`） | ✅ 可用，克隆 ~11 秒 |
| objects.githubusercontent.com（Release 附件） | ⚠️ 下载中途被重置，**优先 git clone 源码** |
| pypi.org | ⚠️ 时通时断，大包会卡死 |
| pypi.tuna.tsinghua.edu.cn（清华源） | ✅ 稳定，`uv`/`pip` 全部走它 |
| kenney.nl | ⚠️ curl 403（Cloudflare 拦 UA），浏览器可开 |
| kenney-assets.itch.io / itch.io / opengameart.org / game-icons.net / blockbench.net | ✅ 200 可开 |

## 五、给 AI 的取用约定

1. **先查本清单再动手**：有现成插件/素材就不自己写。
2. 插件类（LimboAI 等）装进 `addons/`，并在 `project.godot` 的 `[editor_plugins]` 里启用。
3. 素材下载后按 `assets/2d`、`assets/3d`、`assets/audio` 归档，文件名保持来源可追溯。
4. **授权**：CC0 可自由用；CC-BY 必须在游戏内或说明文件署名，别漏。
5. 从 GitHub 装东西一律 `git clone --depth 1 --branch <tag>`，别用 Release zip（CDN 不稳）。
